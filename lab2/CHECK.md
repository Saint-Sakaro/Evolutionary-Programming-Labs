# Проверка лабораторной работы № 2

Дата проверки: **10 ноября 2026 года**.

Работа проверена по общим требованиям и заданию лабораторной № 2 из предоставленной
методички. Вариант **12**, группа **527**, номер **3**.

| Требование | Реализация |

| Маршрут по 15–25 точкам с ограничением времени | 20 клиентов и склад, полный рейс не более 507 минут |
| Дискретное представление | Перестановка обязательных клиентов |
| Специализированный оператор | Собственный OX-кроссовер |
| Допустимость представления | OX, обмен и инверсия не создают пропусков и повторов |
| Временное ограничение | Направленные проезды + обслуживание + возвращение на склад |
| Два подхода к ограничениям | Два коэффициента штрафа, λ=0,1 и 5 км/мин |
| Сравнение операторов | Обмен и инверсия при фиксированном штрафе |
| Два допустимых и два недопустимых примера | В отчёте и examples.json; все примеры — корректные перестановки |
| Минимум 20 запусков | По 20 seed на каждую из четырёх конфигураций ГА и базовую эвристику |
| Сопоставимый бюджет | Ровно 16 000 полных оценок на запуск, включая недопустимые маршруты |
| Базовая конструктивная эвристика | Рандомизированный ближайший сосед по направленному времени, k=3 |
| Понятное итоговое решение | Карта, полный порядок адресов и расписание рейса в CSV |
| Статистика и анализ | Доли успеха, min, mean, median, выборочное std, max, парные разности |
| Воспроизводимость данных | Генератор с seed 5270312; исходный JSON приложен |
| Воспроизводимость алгоритма | Все seed в конфигурации, версии и хеши в manifest.json |
| Сдаваемые материалы | Код, README, Markdown-отчёт, данные, параметры, CSV, графики и блок-схема |

## Выполненные проверки

- **13 тестов** прошли: OX на известном примере и случайных родителях, две мутации,
  направленные времена, обслуживание и возврат, недопустимые хромосомы,
  сохранение допустимого архива, явный неуспех, бюджет и воспроизводимость.
- Скалярными формулами независимо пересчитаны длины, времена и нарушения
  всех 100 возвращённых маршрутов; статистика проверена через statistics.
- Проверены все 20 000 строк истории, число оценок, невозрастание лучших значений,
  расписание рейса, примеры, ссылки и хеши.
- Все **100 запусков** повторены: маршруты, численные результаты и полные истории
  совпали точно. Время выполнения не сравнивалось на точное равенство.
- Просмотрены карта, графики сходимости, итоговое сравнение и блок-схема.

Проверка доступна повторно:

~~~bash
python -m unittest discover -s tests -v
python verify_results.py --repeat
~~~

## Результаты и их границы

Лучший найденный допустимый маршрут: **154,609202 км**, время **436,762804 минуты**,
лимит **507 минут**. Все 20 запусков обеих конфигураций с инверсией нашли допустимые
решения. При обмене допустимыми завершились 19/20 запусков с λ=0,1 и 17/20 с λ=5;
это отражено в отчёте и не скрыто усреднением недопустимых маршрутов.

У обеих конфигураций с инверсией медиана равна 158,911629 км; у базовой эвристики —
186,590002 км. Глобальная оптимальность не заявляется. Нижняя граница по минимальному
остовному дереву составляет 125,925220 км.

Методичка задаёт маршрут с ограничением времени без детальной предметной модели.
В работе явно принята модель полной длительности рейса одного автомобиля.
Штрафные коэффициенты сравниваются в соответствии с приведённым в задании примером;
ремонт маршрута не требуется как дополнительный обязательный метод.
Конечный штраф не гарантирует допустимость, поэтому результат берётся из отдельного
допустимого архива, а отсутствие такого результата явно фиксируется.
