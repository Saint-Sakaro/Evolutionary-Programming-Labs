# Лабораторная № 2

Вариант 12: маршрут доставки по 20 адресам с возвратом на склад.
Нужно сократить расстояние и уложиться в общее время рейса.

## Запуск

Установка окружения описана в [общем README](../README.md).
Команды из папки lab2:

~~~bash
python experiment.py
python -m unittest discover -s tests -v
python verify_results.py
~~~

Сравниваются четыре конфигурации ГА и рандомизированная жадная эвристика.
У каждой 20 seed и бюджет 16 000 оценок маршрута. В ГА меняются два фактора:
штраф за опоздание (0,1 или 5 км/мин) и мутация (обмен или инверсия).
Кроссовер — OX.

Параметры — в [config.json](config.json). Для новой серии:

~~~bash
python experiment.py --config config.json --data data/instance.json --output results_repeat
~~~

## Данные

[data/instance.json](data/instance.json) содержит координаты, направленную матрицу
времени, обслуживание и лимит рейса. Склад — 0, клиенты — 1…20.
Склад добавляется к перестановке при расчёте маршрута.

Данные сгенерированы с seed 5270312. Восстановление набора:

~~~bash
python generate_data.py --seed 5270312 --output data/instance.json
~~~

Лимит выбран по допустимому маршруту-свидетелю. В начальную популяцию
и результаты поисковых методов этот маршрут не добавляется.
