# Лабораторная работа № 2

Группа **527**, номер **3**, вариант **12**: маршрут доставки с ограничением времени.
Один склад и 20 обязательных адресов, евклидовы расстояния, направленная матрица времени,
обслуживание каждого адреса и возврат на склад. Минимизируется расстояние при лимите
общей продолжительности рейса. Все исходные данные приложены.

## Запуск

Требуется Python 3.10 или новее; проверено на Python 3.12. Из папки lab2:

~~~bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python experiment.py
~~~

Для Windows команда активации: .venv\Scripts\activate.
Для точных версий выполненного эксперимента используйте requirements-lock.txt
вместо requirements.txt. После установки библиотек интернет не требуется.
Если окружение первой лабораторной уже установлено, оно также подходит для второй.

Запуск выполняет **100 испытаний**: по 20 различных seed для четырёх конфигураций
ГА и для рандомизированной жадной эвристики. Каждое испытание расходует **16 000**
полных оценок маршрута, включая недопустимые кандидаты и инициализацию.
Четыре конфигурации образуют план 2×2: два штрафа × две мутации.
Общее число оценок — **1 600 000**.

Код использует собственные турнирный отбор, OX-кроссовер, обмен, инверсию,
штрафы, элитизм и архив допустимых маршрутов. Готовые оптимизаторы не используются.
NumPy нужен для массивов и случайных чисел, Matplotlib — для графиков.

Готовые результаты уже находятся в папке results; для чтения повторный запуск не нужен.
При повторном запуске в ту же папку они перезаписываются. Для отдельной серии:

~~~bash
python experiment.py --config config.json --data data/instance.json --output results_repeat
~~~

В config.json можно менять seed и параметры алгоритмов. Нужно минимум 20 различных
неотрицательных целых seed, два разных положительных штрафа и обе мутации.
В исходном конфиге: λ=0,1 и 5 км/мин, мутации swap и inversion.
Между сравниваемыми парами меняется один фактор.

## Данные

[data/instance.json](data/instance.json) содержит координаты в км, времена проезда в минутах,
обслуживание, лимит времени и допустимый маршрут-свидетель.
Склад имеет номер 0, клиенты — 1…20. Хромосома не включает склад:
он добавляется при декодировании в начало и конец рейса.

Матрица времени направленная, с фиксированной синтетической дорожной нагрузкой.
Расстояние и время — разные характеристики, а не одна величина с постоянным множителем.
Данные создаются один раз с seed **5270312**. Полная процедура описана в отчёте.
Восстановление исходного JSON:

~~~bash
python generate_data.py --seed 5270312 --output data/instance.json
~~~

Лимит выбран относительно найденного при генерации допустимого маршрута,
чтобы задача имела решение. Свидетель не используется как стартовая особь и
не подмешивается в результаты поисковых методов.

Статистика расстояний строится по допустимым результатам; доля успешных запусков
указывается отдельно. Отсутствие допустимого решения не маскируется коротким,
но опоздавшим маршрутом. Для проверки сохраняются и лучший допустимый маршрут,
и показатели скалярной штрафной элиты.

У базового метода конструктивная процедура на каждом шаге случайно выбирает одного
из трёх ближайших по времени непосещённых клиентов. Все 16 000 попыток входят в бюджет.
Это рандомизированная жадная эвристика, а не равномерный случайный поиск.
Сравнение проводится по числу полных оценок, а различия стоимости построения кандидатов
отражаются во времени работы и обсуждаются в отчёте.

## Тесты

~~~bash
python -m unittest discover -s tests -v
python verify_results.py
python verify_results.py --repeat
~~~

Проверяются OX на известном примере и на случайных родителях, обе мутации,
направленное время, обслуживание, возврат на склад, неправильные перестановки,
независимый допустимый архив, фактическое число оценок, seed и воспроизводимость данных.
verify_results.py независимо пересчитывает длины и времена скалярными формулами,
проверяет статистику, расписание, ссылки и хеши. Опция --repeat повторяет все 100
запусков и сравнивает точные решения и полные истории; время работы сравнивать
на точное равенство нельзя.

## Структура

~~~text
routing.py          Модель, оценка, операторы, ГА и базовая эвристика
generate_data.py    Воспроизводимый генератор синтетического экземпляра
experiment.py       Серии запусков, CSV, расписание рейса и сведения о среде
plotting.py         Графики и блок-схема в PNG и SVG
report.py           Отчёт по фактическим результатам
config.json         План 2×2, параметры и seed
data/instance.json  Исходные данные
tests/              Автоматические проверки
results/            Готовые материалы для сдачи
~~~

Точный глобальный оптимум не заявляется. Приведена нижняя граница по минимальному
остовному дереву и сравнение с базовой эвристикой при одинаковом бюджете.
