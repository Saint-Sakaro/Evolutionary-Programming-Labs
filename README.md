## Установка

Python 3.10 или новее; результаты проверены на Python 3.12.
Команды выполняются из корня скачанного или клонированного репозитория:

~~~bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
~~~

В Windows: .venv\Scripts\activate вместо source.
Для тех же версий библиотек используйте requirements-lock.txt.
После установки зависимостей доступ в интернет не требуется.

## Воспроизведение

Готовые результаты находятся в папках results. Их можно читать без нового расчёта.
Для отдельных повторных серий:

~~~bash
python lab1/experiment.py --output lab1/results_repeat
python lab2/experiment.py --output lab2/results_repeat
~~~

Точные seed, бюджеты и параметры указаны в config.json соответствующей работы.
Исходные CSV сохраняют полную точность; таблицы отчётов округлены.

## Автоматические проверки

Запускайте тесты каждой работы отдельно, чтобы не смешивать одноимённые модули:

~~~bash
python -m unittest discover -s lab1/tests -v
python -m unittest discover -s lab2/tests -v
~~~

При наличии verify_results.py можно дополнительно проверить сохранённые данные,
а с опцией --repeat — заново выполнить серию и сравнить численные результаты.
Время исполнения при повторении может измениться.

## Структура

Каждая папка labN содержит README.md, код, config.json, tests и results.
Дополнительные входные данные находятся в data.
В results хранятся отчёт, CSV и графики.

Локальные окружения, кеши и повторные серии исключены из Git.
