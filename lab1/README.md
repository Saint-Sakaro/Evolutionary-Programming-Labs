# Лабораторная работа № 1

**Эволюционное программирование и генетические алгоритмы** — группа 527, номер 3,
вариант 12, функция Цин, размерность 5. Реализация на Python с собственными
турнирной селекцией, BLX-α-кроссовером, гауссовской мутацией и элитизмом.
Готовые оптимизаторы не используются. NumPy выполняет операции с массивами
и генерирует случайные числа, Matplotlib строит графики.

## Установка и запуск

Требуется Python 3.10 или новее. Команды выполняются из папки `lab1`:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python experiment.py
```

В Windows вместо `source` используется `.venv\Scripts\activate`.
Для той же версии библиотек, что в приложенном эксперименте,
установите `requirements-lock.txt` вместо `requirements.txt`.
Эксперимент проверен на Python 3.12; точная версия среды записана в `results/manifest.json`.

Команда выполняет **60 запусков**: две конфигурации ГА и случайный поиск,
по 20 различных seed на метод. В каждом запуске — ровно 40 000 оценок функции.
Печатается статистика каждого метода; таблицы, графики и отчёт сохраняются в `results`.
Графический интерфейс и доступ в интернет после установки зависимостей не нужны.
Готовые результаты уже приложены: запускать вычисления для чтения отчёта не требуется.

## Отчёт и результаты

- [Результаты проверки](CHECK.md) — сверка с методичкой и выполненные проверки.
- [Отчёт](results/report.md) — постановка, алгоритм, блок-схема, параметры, результаты и анализ.
- [Сходимость](results/convergence.png) — среднее и диапазон min–max по 20 запускам.
- [Итоговые значения](results/final_values.png) — результаты каждого запуска.
- [Все запуски](results/runs.csv), [сводная статистика](results/summary.csv),
  [истории](results/history.csv) — машиночитаемые данные.
- [Параметры](config.json) — полный план эксперимента и seed.

Отчёт автоматически формируется из результатов вычислений. Его числовые значения
не подставлены вручную. При повторном запуске в ту же папку результаты перезаписываются.
Для отдельного эксперимента используйте другую папку:

```bash
python experiment.py --config config.json --output results_repeat
```

Seed задаются списком `seeds` в JSON. Чтобы сохранить требуемую серию,
нужно не менее 20 различных неотрицательных целых seed. В блоках `configurations`
меняется только `mutation_sigma`; остальные параметры общие. Масштаб мутации
абсолютный, в единицах координат. Вероятность мутации применяется к каждой координате,
вероятность кроссовера — к паре родителей. Одна пара порождает одного потомка.
Поля `student` и `problem` закреплены за вариантом 12 и проверяются при запуске;
для экспериментов изменяйте seed, параметры алгоритма и порог успеха.
Название `random_search` зарезервировано за базовым методом.

Для единичного запуска, например при разборе на защите:

```python
import json
from optimizer import genetic_algorithm

with open('config.json', encoding='utf-8') as f:
    config = json.load(f)
parameters = dict(config['common'], mutation_sigma=0.1)
result = genetic_algorithm(config['problem'], parameters, seed=7)
print(result.best_x, result.best_f, result.evaluations)
```

## Проверки

```bash
python -m unittest discover -s tests -v
```

Проверяются известные значения функции и все 32 глобальных минимума, ограничения,
интервал BLX-α, воспроизводимость, монотонность лучшего найденного значения,
обработка неверных параметров и фактический расход вычислительного бюджета.
Проверка бюджета включает минимальный бюджет, полное и неполное поколения.

## Структура

```text
lab1/
  optimizer.py           Функция Цин, операторы, ГА, случайный поиск
  experiment.py          Серии запусков, CSV, статистика, сведения о среде
  plotting.py            Графики и блок-схема в PNG и SVG
  report.py              Формирование отчёта по фактическим данным
  config.json            Параметры варианта и эксперимента
  requirements.txt       Зависимости с допустимыми диапазонами версий
  requirements-lock.txt  Версии библиотек выполненного эксперимента
  tests/                 Автоматические проверки
  results/               Готовый отчёт, таблицы и графики
```

Начальная популяция равномерна на всей области [-500, 500]⁵.
Аналитические корни ±√i не используются алгоритмами поиска.
Они служат только ориентиром в отчёте и проверкой в тестах.
Глобальный минимум равен 0; измеренные значения являются приближёнными.

Постановка задачи и требования описаны в отчёте; исходные параметры приведены в config.json.
