# Лабораторная № 1

Генетический алгоритм для функции Цин: вариант 12, размерность 5.
Используются турнирный отбор, BLX-α, гауссовская мутация и элитизм.

## Запуск

Установка окружения описана в [общем README](../README.md).
Команды из папки lab1:

~~~bash
python experiment.py
python -m unittest discover -s tests -v
~~~

Эксперимент сравнивает два масштаба мутации и случайный поиск:
по 20 seed на метод, 40 000 оценок функции на запуск.

Параметры задаются в [config.json](config.json). Менять можно seed и настройки ГА;
функция, размерность и границы закреплены за вариантом.
Вероятность мутации относится к координате, кроссовера — к паре родителей.
Масштаб мутации задан в единицах координат.

Чтобы сохранить новую серию отдельно:

~~~bash
python experiment.py --config config.json --output results_repeat
~~~
