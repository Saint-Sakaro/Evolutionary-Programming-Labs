# Лабораторная № 3

Вариант 12, трек A: расписание занятий с тремя критериями —
нарушенные пожелания по времени, окна-пары и поздние занятия.
Пересечения групп, преподавателей и аудиторий запрещены.

## Запуск

Установка окружения описана в [общем README](../README.md).
Команды из папки lab3:

~~~bash
python experiment.py
python -m unittest discover -s tests -v
python verify_results.py
~~~

Сравниваются NSGA-II и портфель взвешенной суммы: по 20 seed и 8 400 оценок
на метод. У портфеля этот бюджет делится между семью наборами весов.

Параметры — в [config.json](config.json). Для новой серии:

~~~bash
python experiment.py --config config.json --data data/instance.json --output results_repeat
~~~

## Данные

В [data/instance.json](data/instance.json) заданы 24 занятия, четыре группы,
четыре преподавателя и пожелания по времени. Шаблон построен так, чтобы критерии
противоречили друг другу: выполнение всех заявок даёт 16 окон-пар и 12 поздних занятий.

~~~bash
python generate_data.py --seed 5270313 --output data/instance.json
~~~

Структура набора фиксирована; seed задаёт перестановку названий предметов.
Заявочное расписание включено одной особью в начальные популяции обоих методов.
Его оценки входят в бюджет.
